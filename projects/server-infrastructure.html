Self-Hosted Server Infrastructure

Live

The home server everything else I build runs on. Treated as production, because for me it is.

  • Raspberry Pi 5 booting from NVMe in a multi-node topology, running containerized services.
  • Private by construction: reachable only over an authenticated mesh VPN, with nothing exposed to the public internet.
  • Nightly automated backups that verify their own integrity and replicate offsite — plus a watchdog that reports silent failures, because a backup that quietly stops running is worse than none.
  • Two security audits against the running system; every high-severity finding closed.
